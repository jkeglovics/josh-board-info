Privacy policy

Google data used by Josh Board

When the owner authorizes access, Josh Board uses Google Calendar event information to display upcoming events and Google Nest device and doorbell event information to show doorbell activity. OAuth credentials maintain these authorized connections.

Storage and sharing

The dashboard, credentials, calendar data, and camera feeds are private. Josh Board uses Google data to operate the owner’s dashboard. It does not sell Google data, use it for advertising, or share it publicly. This informational website is hosted on GitHub Pages and does not request Google account access or include tracking scripts.

Revoking access and removing data

The owner can revoke access in Google Account connections and remove locally stored tokens and integration data from the Raspberry Pi.

Contact

For privacy questions, contact the owner through the jkeglovics GitHub profile.
